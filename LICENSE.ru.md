# LangSleeper

### Умный переключатель раскладки клавиатуры для Windows

**Переключай два основных языка привычным сочетанием клавиш, а третий и четвёртый включай напрямую — отдельными горячими клавишами.**

LangSleeper — лёгкая программа для Windows, созданная для удобного управления несколькими раскладками клавиатуры.

Если ты используешь русский, английский и украинский или любую другую комбинацию языков, LangSleeper помогает избавиться от постоянного перебора раскладок.

**Быстрое переключение. Удобные горячие клавиши. Современный стеклянный интерфейс.**

## Зачем нужен LangSleeper?

Стандартное переключение языков Windows не всегда удобно, особенно если установлено три или четыре раскладки.

Например, ты постоянно используешь английский и русский, а украинский нужен лишь иногда.

Вместо последовательного переключения между всеми языками LangSleeper позволяет:

- Назначить два основных языка.
- Переключаться между ними привычной комбинацией.
- Включать третий язык напрямую отдельным сочетанием клавиш.
- Назначить собственную комбинацию для четвёртого языка.
- Видеть текущую раскладку в компактном индикаторе.
- Полностью отключить индикатор при необходимости.

## Возможности

### Умное переключение языков

Главная особенность LangSleeper — разделение основных и дополнительных языков.

| Действие | Пример |
|---|---|
| Переключение двух основных языков | `Ctrl + Space` |
| Включение третьего языка | `Ctrl + Alt + Shift + U` |
| Включение четвёртого языка | Своя комбинация |
| Перехват стандартного переключения | Опционально `Alt + Shift` |

Все сочетания настраиваются в программе.

### Современный стеклянный интерфейс

Интерфейс LangSleeper создан в стиле современных приложений Windows.

- Полупрозрачные стеклянные поверхности
- Светлая и тёмная темы
- Минималистичный дизайн
- Компактные элементы управления
- Настраиваемая индикация языка

### Компактный индикатор раскладки

При смене языка LangSleeper может показывать небольшую плашку с обозначением текущей раскладки.

Например: **EN · RU · UA**

Никаких длинных уведомлений и лишних надписей.

Если индикатор не нужен, его можно полностью отключить.

### Автозапуск с Windows

Программа может автоматически запускаться при входе в Windows.

### Восстановление настроек при удалении

LangSleeper предусматривает очистку собственных настроек и автозапуска перед удалением программы.

1. Открой [Releases](../../releases).
2. Скачай последнюю доступную версию для Windows.
3. Распакуй архив, если это необходимо.
4. Запусти `LangSleeper.exe`.
5. Настрой основные и дополнительные языки.

**Операционная система:** Windows.

## Пример использования

Допустим, у тебя установлены три раскладки:

- Английская — основная
- Русская — основная
- Украинская — дополнительная

Ты работаешь с английским и русским, переключая их через `Ctrl + Space`.

Когда нужен украинский, нажимаешь отдельную комбинацию, например `Ctrl + Alt + Shift + U`.

LangSleeper сразу включает украинскую раскладку.

Не нужно несколько раз переключать язык и искать нужный в списке.

## Частые вопросы

**Можно ли использовать три или четыре языка?**

Да. Для дополнительных доступных раскладок можно назначать отдельные сочетания клавиш.

**Можно ли скрыть индикатор языка?**

Да. Отображение индикатора отключается в настройках.

**Есть ли автозапуск с Windows?**

Да. Программа поддерживает автоматический запуск.

**Можно ли вернуть стандартное переключение Windows?**

В программе предусмотрена очистка настроек и автозапуска. Работа стандартных сочетаний также зависит от настроек самой Windows.

**Программа бесплатная?**

Да. LangSleeper можно бесплатно использовать в соответствии с лицензией. Изменение исходного кода и распространение ограничены условиями лицензии.
