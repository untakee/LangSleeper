# LangSleeper

Site: https://untakee.github.io/LangSleeper/

### A smarter keyboard layout switcher for Windows

**Switch between your primary keyboard languages. Instantly activate a third or fourth language with custom shortcuts.**

LangSleeper is a lightweight Windows keyboard layout manager designed for multilingual users who want faster, more predictable language switching.

Instead of cycling through every installed keyboard layout, LangSleeper lets you keep two primary languages and assign dedicated shortcuts to additional languages.

**Simple shortcuts. Direct language switching. A modern, glass-inspired interface.**

## Why LangSleeper?

Windows supports multiple keyboard layouts, but switching between three or more languages can become inconvenient.

For example, if you use English, Russian and Ukrainian, you may want to switch between English and Russian normally while accessing Ukrainian only when needed.

LangSleeper is designed to solve exactly that problem.

- Keep your two most frequently used languages as the primary pair.
- Switch directly to a third or fourth language using dedicated hotkeys.
- Avoid unnecessary cycling through installed layouts.
- See your current keyboard language in a minimal floating indicator.
- Customize the interface and language indicator.
- Start LangSleeper automatically with Windows.

## Features

### Direct keyboard language switching

Choose your two primary keyboard layouts and assign separate keyboard shortcuts to additional languages.

| Action | Example |
|---|---|
| Switch between primary languages | `Ctrl + Space` |
| Activate a third language | `Ctrl + Alt + Shift + U` |
| Activate a fourth language | Custom shortcut |
| Override standard language switching | Optional `Alt + Shift` handling |

Shortcuts can be customized in the application settings.

### Modern glass-inspired interface

LangSleeper features a clean Windows interface inspired by modern desktop applications.

- Translucent, glass-inspired surfaces
- Light and dark themes
- Compact language indicator
- Minimal visual distractions
- Customizable indicator visibility

### Minimal language indicator

Quickly identify your active keyboard language using a compact floating indicator.

Examples: **EN · RU · UA**

The indicator can be disabled completely in settings.

### Windows startup

Launch LangSleeper automatically when you sign in to Windows.

### Restore Windows behavior

LangSleeper provides an option to clean up its application settings and startup configuration before removal.

## How it works

Suppose your Windows keyboard layouts are:

- English — primary language
- Russian — primary language
- Ukrainian — additional language

With LangSleeper, your primary shortcut switches between English and Russian.

A dedicated Ukrainian shortcut activates Ukrainian immediately without requiring you to cycle through all installed languages.

You can configure additional shortcuts for other available layouts.

## Frequently asked questions

**Does LangSleeper replace Windows keyboard layouts?**

No. LangSleeper works with keyboard layouts configured in Windows.

**Can I use three or four keyboard languages?**

Yes. You can assign dedicated shortcuts to additional available layouts.

**Can I disable the language indicator?**

Yes. Indicator visibility is configurable.

**Can LangSleeper start with Windows?**

Yes. Windows startup is supported.

**Can I restore the original keyboard switching behavior?**

LangSleeper includes a cleanup option for its configuration and startup settings. The exact behavior depends on your Windows keyboard settings.
